# Lesson sources: Units 7–12

Official pages each lesson was checked against on 2026-10-20. An independent
auditor read every page listed (as source files from the rust-lang GitHub
repos, since doc.rust-lang.org was not reachable from the build machine), then
the lessons were corrected where they disagreed. Audit notes, with quotes and
the fixes made, are kept in the project's review files (reviews/2026-10-20/).

Fast-track notes that compare Rust with other languages were checked against
those languages' official docs where reachable (Python docs, MDN, the Go spec,
OpenJDK sources, the C++ working draft), mostly for Units 9–12. Some Java, C#,
C++, Python and JavaScript comparisons, especially in Units 7–8, rest on the
auditor's knowledge rather than a primary source.
