# Lesson sources: Units 0–6

Official pages each lesson was checked against on 2026-10-20. An independent
auditor read every page listed (as source files from the rust-lang GitHub
repos, or the local cargo man pages for two Cargo pages, since doc.rust-lang.org
was not reachable from the build machine), then
the lessons were corrected where they disagreed. Audit notes, with quotes and
the fixes made, are kept in the project's review files (reviews/2026-10-20/).

Unit 0 is a general introduction to programming; its Rust statements were
checked against the Book. Comparisons with other languages in fast-track notes
were checked against those languages' primary docs, as described in
u7-u12.md.
