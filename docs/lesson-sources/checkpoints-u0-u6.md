# Checkpoint sources: Units 0–6

Official pages each checkpoint challenge was checked against on 2026-10-21.
Every page listed was opened on doc.rust-lang.org and the specific sentence or
example behind each Rust claim in the challenge text, and behind each standard
library item used by the solution, was found on it. The solutions were also
compiled and run with `rustc --edition 2024 -C opt-level=1 -C overflow-checks=on`
(through `tool/check_lessons.py`), and each function was called with extra
inputs in a throwaway `#[test]` module. Compiler checks alone were not treated
as enough: the pages below are the source for what the text says.

Two limits to know about. The messages `invalid digit found in string` and
`cannot parse integer from empty string` (printed by u6-check) are not written
on the std documentation pages; they come from the `Display` impl of
`ParseIntError` in the standard library source, which is linked below. For
that reason the other challenges print only floats with a fraction, and print
derived `Debug` output only for unit and tuple variants, because the `Debug`
page says derived formats are not stable.
