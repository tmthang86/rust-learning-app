# Quiz explanation sources

Every quiz question has an `explanation` (English in
`assets/content/lessons/<id>.json`, Vietnamese in
`assets/content/vi/lessons/<id>.json`), shown after the learner taps Check,
whether the answer was right or wrong. It says why the right answer is right
and, where it helps, why the other options are not.

The explanations restate what the lesson itself teaches, so their sources are
the official pages each lesson was checked against. The table repeats those
pages per lesson (from [u0-u6.md](u0-u6.md), [u7-u12.md](u7-u12.md),
[checkpoints-u0-u6.md](checkpoints-u0-u6.md) and
[checkpoints-u7-u12.md](checkpoints-u7-u12.md), where the notes on how each
page was read are kept). A claim in an explanation that its lesson does not
already make must be checked against one of these pages, or a page added
here, before it ships.

`tool/check_lessons.py` fails when a question has no explanation, in English
or in a translation, and checks that code mentioned in the English
explanation is copied as is into the translation.
